## 觀察與待決策

1. 清怪驗收：14 條三轉路線 全部在中位數 ±15% 內（共 5 個檢查點）。調整清單見 packages/content/src/effects/balanceAdjustments.ts。
2. 打王比較：修羅武聖（15.0%）、命運魔術師（-19.5%）、千面幻術師（-23.0%） 超出 ±15%。牌術與幻影路線的打王輸出偏低是結構性（單體牌、功能性花色、低係數召喚），只調係數效益遞減，建議下一輪改機制而不是再加倍率。
3. 成長曲線：同投入（Q3 主屬性、L=10m）在第 9、10、11、12 圖所有路線都打不贏王；BOSS 血量每圖 ×1.5，而本模型的投入只隨等級線性成長。需要決定：參考等級曲線、或後期依賴的品質／詞條／傳說強度（規格原文未提及目標過王等級）。
4. 換圖收益：打贏 BOSS 進入下一圖後，每分鐘古物增加 139.9%～198.9%。原因是下一圖第 1 關血量約為本圖第 29 關的一半、每隻產出 ×1.4；這是規格公式的直接結果，若要平滑需調整 HP(m,n) 或 w(m)。
5. 二轉：狂劍士（31.1%）、破陣騎士（26.6%）、馴獸師（19.0%）、影刃刺客（-19.4%）、武僧（16.4%）、戰鎚鐵匠（15.5%） 超出 ±15%；一轉共用範圍招（橫掃斬）讓劍士系二轉偏強。規格驗收只針對三轉，列為下一輪。
6. 鑑定台：以本模型推算每升一級只需 1.1～2.6 分鐘（全部出售），代表參考等級下金幣產出偏快；與第 3 點一起取決於實際成長曲線，暫不調整費用。
